# WhatsApp Chat (GREEN-API)

Минимальный веб-интерфейс для отправки и получения текстовых сообщений WhatsApp через GREEN-API, во внешнем виде web.whatsapp.com.

## Требования реализованы
1. Пользовательский интерфейс для отправки/получения сообщений в WhatsApp — React (Vite + TypeScript)
2. Сервис GREEN-API — https://green-api.com/
3. Только текстовые сообщения
4. Внешний вид — по мотивам web.whatsapp.com (тёмно-зелёная шапка, зелёные исходящие пузыри, боковая панель чатов)
5. Минимальный набор функций — экран входа, список чатов, окно переписки, поле ввода
6. Отправка сообщений — метод `sendMessage` (`src/api/greenApi.ts`)
7. Получение сообщений — `receiveNotification` / `deleteNotification` (technology HTTP API), опрашиваются в цикле (`src/App.tsx`)
8. React

## Запуск
```bash
npm install
npm run dev
```
Откройте http://localhost:5173, введите `idInstance` и `apiTokenInstance` вашего авторизованного инстанса GREEN-API (WhatsApp-аккаунт должен быть подключён и иметь статус `authorized`).

## Как это работает
- **Вход**: экран логина проверяет данные вызовом `getStateInstance` и пускает дальше только если инстанс авторизован.
- **Новый чат**: в сайдбаре вводится номер телефона получателя → создаётся `chatId` вида `<номер>@c.us`.
- **Отправка**: `POST /waInstance{id}/sendMessage/{token}` с `{ chatId, message }`.
- **Приём**: цикл в фоне вызывает `GET /waInstance{id}/receiveNotification/{token}` (long-polling до 20 сек), при получении уведомления типа `incomingMessageReceived` сообщение добавляется в нужный чат, после чего уведомление удаляется через `DELETE .../deleteNotification/{token}/{receiptId}`, чтобы не обработать его повторно.

## Ограничения этого прототипа
- Учётные данные инстанса и вся история чатов хранятся только в памяти браузера (обновление страницы = разлогин).
- Один активный запрос `receiveNotification` на вкладку — сообщения в другие чаты, кроме открытых через "Начать чат", не появятся сами по себе, пока чат не создан (входящее сообщение от нового номера тоже создаёт чат автоматически).
- Запросы к GREEN-API идут прямо из браузера, поэтому `apiTokenInstance` виден в сетевых запросах.
